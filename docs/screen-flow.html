画面フロー

Figma「推し活2」の PC版36画面 + スマホ版2画面（全38画面） をそのまま再現したプロトタイプです。 Figma 側は ⓪共通 / ①購入 / ②出品 / ③やりとり / ④マイページのタブ / ⑤運営オペレーション / ⑥モバイル の7セクションに分かれており、 ここでも同じ並びにしています。セクション内の遷移（Flow/◯◯）を実線のボタン、画面内リンクから読み取れる遷移を破線のボタンで表しています。 画面の中のボタンそのものを押しても遷移します（点線の枠が出る箇所）。 それ以外のボタン・チップ・チェック・トグル・星なども本番と同じように反応します。 画面が変わらない操作（保存・申請・削除など）は、結果を画面下部の通知で知らせます。

新規会員登録は「パスワードを2回入力 → メールに届いた6桁の確認コードを入力」です。ログイン画面はタブで フォームそのものが入れ替わり、確認コードの入力（PC・スマホ）へ進みます。 この変更は Figma の2ファイル（推し活2 / 推し活）へ反映済みです。Figma 側は新規登録タブを 別フレーム（2167:1976）として持つので41画面、こちらはタブの状態として実装しているので40画面です。

右上の PC 1270 / タブレット 834 / スマホ 402 で表示幅を切り替えられます。 スマホ幅にすると、スマホ版が用意されている画面はそのデザインに切り替わります（検索・作品詳細・カート・ 決済・マイページ・注文詳細・通知・マイぬい、そしてログインまわり）。用意がない画面は、PC 用の組みを そのまま畳んで「本番の CSS でどう折り返すか」を確かめるための表示です。 スマホの11画面は Figma の2ファイルへ反映済みで、⑥モバイルのレーンに並んでいます。
