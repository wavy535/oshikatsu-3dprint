## 画面一覧（Figma：全47画面）

PC は 1270×720（36画面）、モバイルは 402×874（11画面）で作成しています。キャンバスは 7 本のレーンに分かれ、レーン内の矢印が遷移のきっかけ（ボタン名）、レーンをまたぐ矢印が分岐と連携を表します。Figma のファイルは「推し活2」と「推し活」の2つで、常に同じ内容に保っています。クリック可能なプロトタイプ（全47画面を1枚の HTML で再現し、PC／タブレット／スマホの幅を切り替えられる）は `design/oshinest-screen-flow-47` ブランチの `docs/screen-flow.html` にあります。

| レーン | 内容 |
|---|---|
| ⓪ 共通（入口） | Top（未ログイン）→ ログイン → 新規会員登録 → 確認コードの入力 → Top（ログイン中）。買う人・作る人で共通 |
| ① 購入フロー | 検索結果 → 作品詳細 → 作品詳細｜レビュー → 作品詳細｜Q&A・発送 → カート → 決済 → マイページ（購入履歴）→ 注文詳細 → 受け取り評価 |
| ② 出品フロー | STEP1 →（検証NG時）STEP1エラー → STEP2 → STEP3 → STEP4 → 作品管理 → 修正依頼 → 売上 → プロフィール編集 |
| ③ やりとり・相談 | 公開プロフィール → メッセージ → オーダーメイド相談 → オーダーメイド見積り |
| ④ マイページのタブ（使う頻度順） | 通知一覧 → お気に入り一覧 → マイぬい → ぬいを登録 → 配送先・お支払い → 通知設定 |
| ⑤ 運営オペレーション | 印刷キュー → 印刷ジョブ詳細 → 検品・発送登録（暗色ヘッダーで買う人・作る人の画面と区別） |
| ⑥ モバイル | ログイン → 確認コードの入力 → ホーム、買う導線（検索結果 → 作品詳細 → カート → 決済 → マイページ → 注文詳細）、マイページのタブ（通知一覧・マイぬい） |

レーンをまたぐ導線は10本です（Figma では `Flow/⓪→①_作品をさがす` のような名前のフレーム）：ログイン後 Top → 検索結果（作品をさがす）／ログイン後 Top → STEP1（作品を投稿する）／マイページ → 作品管理（クリエイター管理へ）／作品詳細 → 公開プロフィール（クリエイターを見る）／マイページ → 通知一覧など（マイページのタブへ）／決済 → 印刷キュー（注文が運営キューへ）／見積り → 決済（見積りを承認して決済）／通知一覧 → 注文詳細（通知から注文詳細へ）／検品・発送登録 → マイページ（発送済みに更新）／検品・発送登録 → 修正依頼（モデル側NGは修正依頼）。

全画面のヘッダーロゴには Top へ戻るプロトタイプリンクを、ヘッダーのベルには通知一覧へのリンクを張ってあります。サイドバーの全行も対応する画面へつないであり、押しても何も起きない行はありません。並びは使う頻度順で、購入履歴 → 通知 → お気に入り → メッセージ → マイぬい → 配送先・お支払い → 通知設定 → （クリエイター）作品管理 → 売上管理 → プロフィール編集 です。

以前あった「⑦ 参考：うちの子で見る（アストラ連携）」の2画面（ぬいスキャン／作品詳細｜うちの子で見る）は、実現可否が未確定のため Figma から削除しました。アストラ連携の構想は保留です。

## デザインシステム

Figma 上に「Design System — OshiNest」セクションとして定義しています。

- **カラートークン**：brand `#0096FA` / text `#1F2328` / muted `#6B7280` / surface `#FFFFFF` / surface-muted `#F5F7FB` / border `#E4E7ED` / success `#2FA36B` / danger `#E5484D` / star `#FFB020`
- **角丸**：sm 6 / md 8 / lg 12 / pill 999
- **余白**：4 / 8 / 12 / 16 / 24 / 32
- **アイコン**：24×24 の線アイコン28種をコンポーネント化
- **コンポーネント**：ボタン（Primary / Secondary / Ghost / Danger、md・smサイズ）、アイコンボタン、チェックボックス、ラジオ、トグル、入力欄、チップ、アバター

各トークンには CSS 変数名（`var(--color-brand)` など）を設定済みなので、実装時にそのまま利用できます。
