# 画像を参考にした有機的な装飾の試作

2026-09-29。参考はユーザーが提示した炎・蔓状の銀色フレーム。材質・反射の再現は対象外。画像そのものはリポジトリへ保存していない。

## モデル設定の更新

ユーザー指定により、現在の通常編集・自由形状の既定モデルはともに `gpt-6-astra`。APIのモデル一覧と個別取得で利用可能を確認した。実APIで先端半径1箇所の部分編集が1呼び出しで成功し、メッシュ検証と3MF/GLB/USDZ出力まで確認。記録は [astraの実行結果](ornament-astra-01/result.json)。以下の01〜15の実験は切替前の履歴であり、astraによる結果とは扱わない。

## 到達点

画像から装飾フレームを実AIで生成し、メッシュ検証の診断を返して修正。続いて部分編集で装飾を増やし、先端半径だけの変更も確認した。造形コードを人手で修正して完成品にすることはしていない。生成形状は全工程でAIの出力であり、エージェントはプロンプトの具体化、見た目の評価、造形APIと検証機能の実装を担当した。

最終サンプルは65×95×約11.58mm、13,764三角形、連結した閉じたメッシュ。中央開口を含めトポロジー上の貫通穴は2個。ブラウザで読み込み、表示、3MF出力まで確認。

**写真と同等の再現度にはまだ達していない。** 平らな枠が目立ち、装飾の密度・分岐・滑らかな溶け合いは写真より単純。曲線の指定を増やすだけで参考画像を再現できるとは評価しない。初回からこの形が得られたわけでもなく、見た目を確認して複数回の指示が必要だった。

## 実装

- `stroke(controlPoints, radii, depthRatio)`：4制御点の3次ベジェ、半径もベジェ補間。Z方向を扁平にできる。先細り・膨らみ・曲がったリボンを表現する。24分割した楕円体間の凸包を結合する近似で、滑らかな面同士のフィレットや彫刻全般を扱うものではない。1部品24本、半径0.4..12mm、厚み倍率0.25..1。既存の三角形数・WASM Workerの時間上限も維持。
- `roundedBox(size,radius)`：角丸枠の輪郭コードを毎回AIに書かせる必要を減らす。XYの角丸、Z方向は平ら。
- `program.edit`：トップレベル変数の初期値の式だけを置換する。ASTで式を検証し、代入・配列の変更・文の注入を拒否。他のコード、色、配置、sizeは保持。これは構造上の保持であり、共有パラメータを変更した際の幾何的な影響範囲まで一般に保証するものではない。
- 診断：寸法超過の実測値、分離した形の座標範囲をAIへ返す。
- ハーネス：画像添付・自由形状の編集には専用の短い造形スキルと `gpt-4.1` を使う。通常のおうち編集は `gpt-4.1-mini`。`gpt-5-mini` の試行も残したが、既定には採用していない。選択根拠は今回の実行で生成・修正・部分編集が成立したこと。統制したモデル比較による優劣の結論ではない。
- 元の認証・1要求の修正回数・日次枠・操作中止・取り消し・既存状態の保持は維持。実験回数の上限を設けないという依頼は、本番サービスの安全上限の撤去とは解釈していない。

## 検証

- 単体・統合テスト366件成功、既存7件skip。型検査、ESLint、ビルド成功。
- ブラウザE2E10件成功。実AIの記録した部分編集を再生し、実WASMで形状生成、3MF保存、同梱設計の一致、取り消しを確認。E2E自体で有料APIは呼んでいない。
- [部分編集の検証](ornament-verification.json)：5つの前後ペアで、対象以外のASTと設計属性の保持、全辺を2面が共有する閉じたメッシュ、貫通穴を確認。
- 最終サンプルをChromiumで読み込み・表示・保存。結果は `ornament-15/browser-checks.json`。実印刷、強度、最小肉厚、スライサーのサポート設定、実機ARは未検証。
- 見た目の評価・再指示は今回エージェントが行った。アプリ内でプレビューを自動撮影し、AIが写真と比較する自動ループは未実装。

## 実行方法

更新後のアプリで「設計を開く・ファイルに保存」から上記JSONを読み込める。古いデプロイは新APIと部分編集を解釈できない。

```bash
# 有料APIを呼ぶ。既存の出力先は上書きしない。
node --experimental-strip-types scripts/evaluate-ornament.ts --live --model=gpt-4.1 --image=/path/reference.png --out=/tmp/new-ornament-run
# 部分編集・メッシュの記録検証（APIなし）
node --experimental-strip-types scripts/verify-ornament-edits.ts
# ブラウザ表示・保存の検証（別ターミナルでnpm run preview -- --port 3000）
node scripts/inspect-ai-samples.mjs docs/examples/ornament-15
```

次の課題は、写真の特徴と表示結果を比較して形を修正する工程、画面上の部位と編集対象の確実な対応、曲面同士のなめらかな接続。現在の成果を、任意の画像を自在に立体化できる完成品とは扱わない。
