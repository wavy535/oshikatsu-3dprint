# UIの再設計（2026-09-28）

## 目的と正本

推しぬいのおうち・家具を探す人が、文字を読み、サイズを確かめ、次の操作を選べる画面にする。一般会員の公開条件、作品・注文・製造の業務処理、Cloudflare構成は維持する。最新の画面とトークンの正本は `src/app` / `src/components` / `src/app/globals.css`。Figmaの過去稿は変更していない。

## 見直した点

- 深緑のアクセント、明るい背景、濃い本文色に統一。本文は16px、補足・メニューは14pxを基本とし、価格や件数以外に9〜13pxの固定文字サイズを使わない。小さなカート件数バッジは12pxの例外。
- ページ見出しは24〜32px、セクション見出しは18〜24px。余白・行間・入力欄・フォーカス表示を共通化。主要ボタンとナビゲーションの操作領域は44px以上。
- スマートフォンの上部に多数の操作を積まず、「さがす・マイぬい・カート・マイページ」を下部に配置。現在地は背景・太字と `aria-current` で示す。下端の安全領域と本文・フッターの余白を確保する。
- トップはサービスの説明、作品への入口、カテゴリ、利用の流れの順。おうちのイラストはサービスのイメージと明記し、販売中の商品やAI生成結果として扱わない。準備公開・デモ注文であることも示す。
- 検索は見出し、検索欄、条件、件数、並べ替え、作品カードを整理。選択中の条件を個別に解除できる。結果なしの場合は条件解除へ、公開作品がない場合はマイぬい登録へ案内する。
- ログイン・登録はフォームを中心に配置。スマートフォンでは大きな紹介パネルを省略し、入力から始められる。入力目的のautocompleteと送信エラーの通知を追加。
- マイページはマイぬい・お気に入り・購入履歴への入口と登録情報を分ける。技術上のrole名は会員向けの日本語表記に変更。制作・運営の入口は権限のある利用者にだけ表示する。
- 制作・管理を含む既存ページ全体の極小文字を解消。管理画面にはページ見出しと作業の説明を追加し、数値・表・フィルタの読みやすさを揃えた。
