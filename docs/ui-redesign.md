# UIの判断基準

購入者がぬいのサイズに合う作品を探し、寸法と購入条件を確認できる画面にする。制作画面にはチャットとプレビューを置き、変更箇所を確認して取り消せるようにする。

## 構成と表現

- トップは「推しぬいのおうちと家具」を示し、身長とカテゴリを一つの検索フォームで選ぶ。HTMLのGETフォームでJavaScript無効時も検索できる。未指定は「すべて」。
- 販売対象はおうち・椅子・台座のSVG構成図で説明する。実物写真の代用を販売実績として見せず、架空の作品や価格を作らない。
- カテゴリ・マイページの操作は用途を併記した一覧で示す。検索結果が空なら、該当作品がないことと検索条件を解除する方法を示す。
- 白地・濃い文字・罫線を基本に、青 `#1d4ed8` を主要操作・選択状態へ使う。角丸は小さくする。色だけに頼らず、太字・罫線・`aria-current` を併用する。
- 認証画面は1列のフォームと操作名を中心にする。装飾用のWebフォント・アニメーションを追加しない。
- デモ注文・申請停止など利用条件を明記する。未配備の機能を利用できると広告しない。

検索や寸法確認の邪魔になる大きな装飾カード、内容のない宣伝文は使わない。図や写真は商品を説明するために使う。

## 操作・可読性

本文16px、補助文字14px以上、スマホの入力欄16px以上、主な操作44px以上を基準にする。フォーカス表示・スキップリンク・モバイル固定ナビ・safe-areaを維持する。アバターや通知ドット、成功・注意・エラーの意味は保つ。

320pxの横はみ出し、キーボード操作、主要ボタンのコントラスト、検索のJavaScript有無をE2Eで確認する。必要CSSと完全CSSの比較も維持する。ユーザビリティ調査は未実施。

検証は [テスト方針](testing.md)、性能は [性能設計](performance.md) を参照。
