# UIの判断基準と再設計（2026-09-28）

## 現在のトップページ

ユーザーからトップページの再設計を依頼され、文字と罫線だけになっていた構成を再評価した。販売対象の形が分からず、身長とカテゴリを別々の場所から選ぶ画面になっていたため、次のように変更した。

- 最初に「推しぬいのおうちと家具」を示し、身長とカテゴリを一つの検索フォームで指定できるようにした。GETで既存の作品一覧に渡すため、JavaScriptの起動前・無効時にも検索できる。未指定は両方「すべて」とする。
- 青い面に、背景・椅子・台座の組み合わせと幅・奥行きを示すSVGの構成図を置いた。一般的なぬいのシルエットを使い、実在する販売作品と誤認しないキャプションを添えた。現在は掲載できる実物写真がなく、架空の販売作品や価格を作らないための選択。実作品の掲載時は写真に置き換える余地がある。
- カテゴリは用途を併記した一覧にし、下にサイズの測り方とマイぬいへの導線を配置した。準備公開中・デモ注文であることはヒーロー直下、制作機能・申請停止は「作品をつくりたい方へ」に明記した。
- フォント・アニメーション・画像リクエスト・クライアント依存の状態管理は追加しない。SVGをServer ComponentとしてHTMLに含め、既存の必要CSS抽出と圧縮を維持する。LCPの計測条件も変えない。

320 / 390 / 1365pxで見た目と横はみ出しを確認。320pxでは長い選択肢が切れたため、ラベルを残して未指定の表示を「すべて」に短縮した。スマホの組み合わせ検索をJavaScriptあり・なしで確認し、6画面の必要CSSと全CSSの一致、主要ボタンのコントラスト、キーボード操作も継続して検証する。自己点検であり、ユーザビリティ調査を実施したという意味ではない。

以下は先の全画面再設計の経緯。トップページの構成についてはこの節を優先する。

## 前回案の再評価

前回（99f2700）の淡い緑・大きな角丸・イラスト付きヒーロー・3列カードは撤回した。文字の可読性は改善したが、用途に対して装飾が多く、ユーザーから「AI slopっぽい」と指摘された。以下はデザインの主観的な評価であり、AI製かどうかを判定する基準ではない。

調査した資料:

- [Anthropic: Improving frontend design through Skills](https://claude.com/blog/improving-frontend-design-through-skills)：指示が曖昧な生成では、似た配色・レイアウトに収束しやすいという開発元の説明。記事中のフォント・アニメーション等の推奨をそのまま採用するのではなく、OshiNestの目的に必要かを判断した。
- [Nielsen Norman Group: AI Prototyping in Real Design Contexts](https://www.nngroup.com/articles/ai-prototyping/)：AIの見栄えの良い試作でも、利用者のタスクに合わない情報の強調や汎用的な構成が残るという観察。
- [925Studios: AI Slop Fonts and Gradients](https://www.925studios.co/blog/ai-slop-design-tells)：同じ形の角丸カード、薄い線のアイコン、具体性のない宣伝文を定型パターンとして挙げるデザイン事業者の見解。普遍的な法則としては扱わない。

## 照合と変更

| 前回の画面で確認したこと | 今回の変更 | 利用者にとっての理由 |
| --- | --- | --- |
| 淡緑の大きな面と角丸の白いカードをほぼ全画面で繰り返す | 白地、墨色の文字、罫線で区分。角丸は2〜4px程度に抑える | 重要度を装飾の量ではなく見出し・配置で区別する |
| 色付きの囲みにイラストを置いた大型ヒーロー | 10・15・20cmの対応作品への直接リンク | 最初に必要な「ぬいに合う作品を探す」をその場で始められる |
| 同じアイコン付きカードが3枚並ぶ | カテゴリ・マイページの操作を罫線付きの一覧にする | 項目名と具体的な用途を見比べやすい |
| 「とっておきの居場所」「小さな世界」「出会うまで」 | 「おうちと家具を探す」「台座・家具・背景」「寸法を確認」 | 実際に何ができるかが分かる |
| ログイン画面にもイラストと宣伝文がある | 1列のフォームと「ログイン」「新規会員登録」の見出し | 認証操作に集中できる |
| 空の作品一覧で情緒的に会員登録を促す | 公開作品がないこと、条件解除・サイズ登録の用途を明記 | 現在の状態と次の操作を理解できる |

## 維持する基準

- 本文16px、補助文字14px以上。フォームの入力欄はスマホで16px以上。
- 主な操作は44px以上。フォーカス表示、スキップリンク、モバイル固定ナビ、safe-areaを維持。
- 円形のアバターや通知ドットまで一律に四角くしない。成功・注意・エラーの色は意味のある状態表示として残す。
- ユーザーの指定に合わせ、青 `#1d4ed8` は主要操作・選択状態に使用（赤茶の案から変更）。色だけで選択を伝えず、罫線・太字・aria-currentも用いる。
- 装飾用のWebフォントやアニメーションは追加しない。作品の写真・価格・寸法を優先する。架空の作品や販売実績を埋めない。
- 注文はデモ、クリエイター申請は停止中。AIによる生成は未実装なので、使える機能として広告しない。
