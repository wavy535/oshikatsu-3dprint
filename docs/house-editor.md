# ブラウザ制作機能（2026-09-28）

追記：丸・楕円の窓、複数家具と検証・修正の拡張は [AI制作能力の拡張](ai-design-parts.md) を参照。以下は初回実装時の記録です。

`/create` に、CAD未経験者が寸法と部品を選んでぬいのおうちを作る試作を追加した。専用ブランチ `feat/browser-house-editor` からPRでレビューする。今回の作業にマージ・本番配備は含めない。

## できること

- 幅・奥行・高さ・板厚、壁・屋根・中央の窓・棚の編集、部品選択と色変更、ぬいの寸法による確認。
- 50件までの取り消し・やり直し。端末内の1枠へ明示保存し、再度開く。JSONファイルで保存・読込（128KiB上限、バージョンと範囲検証）。クラウド保存ではない。
- 部品別3MFと設計JSONをまとめたZIP、組み立て状態のGLB/USDZを書き出す。印刷用は部品を個別に回転して接地する。
- 同じ設計からAR用データを生成する。ブラウザではGLBの読み込みまで検証済み。Quick Look / WebXRの実機ARは未検証。
- 初回読み込み後の寸法編集・ファイル保存はオフラインでも動く。オフラインでの新規起動を保証するPWAではない。

## 構成と判断

`src/lib/design` の文書・履歴・部品定義・形状生成・書き出しはReactやDOMから独立させた。UIは `src/components/design`。Three.jsは表示操作時だけ描画し、Manifold 3.5.4のWASMは専用Web Workerで動かす。トップページでは制作エンジンを読み込まない。

形状キャッシュは32件。表示位置や色だけの変更で形状を再計算しない。Workerは実行中1件と最新プレビュー1件に集約し、書き出しを優先する。20秒で応答しなければ停止し、設計を保持して再試行できる。古い世代の結果は画面へ反映しない。WASMの中間オブジェクト、Three.jsの資源、Blob URLを解放する。

既存のGLB/USDZエンコーダーを再利用し、USDZのCRC計算だけをブラウザでも動く純粋関数へ置換した。NodeのCRCとの一致と既存USDZ試験で確認した。

今回は既存TypeScriptとManifoldで一通り作れることを優先した。Rust・MoonBitで独自形状カーネルを作る判断は保留。言語間の性能比較は行っておらず、WASM化一般の優位性を実証したものではない。

## ヘッドレスでの利用

Node.js 24で、ブラウザから保存した設計を同じコアで書き出せる。既存出力ファイルは上書きしない。

```bash
npm run design:export -- house.oshinest.json parts.zip
npm run design:export -- house.oshinest.json house.glb
npm run design:export -- house.oshinest.json house.usdz
npm run benchmark:design
```

## 製造上の制約

部品を接着して組み立てる試作であり、ジョイント・公差設計はない。切妻の前後は開いている。窓は背面中央の四角形、棚は1個。部品の閉じたメッシュ・正体積、板厚、窓の余白、棚の範囲、造形領域を検査するが、実プリントの成功を保証しない。

最小板厚2mm・造形領域256mm角は暫定値。材料・プリンタに合わせた認証値ではない。ぬいの寸法と内寸の比較も補助であり、棚との干渉やぬいの変形は目視確認が必要。スライサー・接着・強度・実機造形の検証は次の段階。

AI生成、任意形状の編集・インポート、クラウド保存、公開・注文との自動連携は含めない。既存投稿へ持ち込む場合も従来の検証が必要で、クライアントの検査結果を製造承認として扱わない。

## 検証と計測

単体試験は文書検証・履歴、閉じたメッシュと窓の体積、3MF再読込・色・寸法、ARの単位、Workerの集約とタイムアウト、CLIの全形式と上書き拒否を対象とする。既存試験を含め289件成功、外部サービス依存7件は対象外。型検査・lint・本番ビルド成功、npm auditは検出0件。

ブラウザでは320px/390px/PC、編集・履歴・保存復元・不正入力・3MF出力・ARデータ読込・オフライン編集・WASM読込失敗からの再試行を検証する。既存ホーム・可読性・CSS抽出を含め、最終版で14件成功。

計測条件: Node 24.13.0、Linux、Intel Core Ultra 7 255H。各ケース10回ウォームアップ後30回、キャッシュを毎回消す場合と再利用する場合を比較し、出力頂点・インデックスのSHA一致を確認した。

| ケース | キャッシュなし中央値 | 再利用中央値 |
| --- | ---: | ---: |
| 基本 | 0.741ms | 0.067ms |
| 大きな窓 | 0.508ms | 0.051ms |
| 棚あり | 0.776ms | 0.063ms |

この実行のWASM初期化は12.35ms。ブラウザの初回ダウンロードを含まない。WASM配信資産は541.47kB（gzip 207.94kB）。ローカルChrome・CPU4倍減速・1365×900・20回の寸法変更では描画反映まで最終版で中央値340.5ms、p95 357.2msを記録した（プレビュー高さ480px）。80msの入力集約・試験操作・描画待ちを含み、実機スマホやネットワーク越しの性能保証ではない。

本番ビルドをローカルで検証する場合は、既存DBの保存先を明示する。検証のために既存DBをseedし直さない。

```bash
npm run build
npx wrangler dev --config dist/server/wrangler.json --port 3000 --ip 127.0.0.1 --persist-to .wrangler/state
# 別ターミナルで実行
npx playwright test tests/e2e/design.spec.ts tests/e2e/home.spec.ts tests/e2e/ui-readability.spec.ts tests/e2e/critical-css.spec.ts
```

自由形状コード、画像入力、実メッシュ修正の追加仕様・検証状況は [自由形状のAIモデリング](freeform-modelling.md) を参照。
