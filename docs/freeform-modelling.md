# 自由形状モデリング

家具・装備・装飾を、固定テンプレートに加えて複合部品と制限付きコードで表現する。会話・画像入力・利用枠・修正予算は [AIチャット](design-ai-chat.md) を参照。

## データと実行方式

| 形式 | 内容 | 上限 |
| --- | --- | --- |
| 複合部品 `custom` | box / cylinder / sphereの追加・差分、寸法・回転・配置 | 3部品、各12演算、外寸各方向2〜200mm |
| 自由形状 `programs` | `{id,name,x,y,color,size,source}` | 3モデル、申告外寸各方向2〜200mm、ソース12,000文字 |
| 単体モード `scene:object` | 床・壁・屋根を出力せず家具・複合部品・自由形状を残す | 元のおうち設定は保持 |

旧設計は欠けた配列と `scene:house` を補って読める。設計JSON全体は128KiBまで。

コードはAcornで構文木へ変換し、専用インタプリタで評価する。`let/const`・`for`・配列・数値演算・限定したMath関数を許可し、関数定義・任意プロパティ・import・ネットワークは許可しない。`eval` / `Function` / 生成JSモジュールを使わない。

ブラウザの専用WorkerでManifold WASMを使い、同じコアをNode CLIからも実行する。WASMオブジェクトを生成コードへ渡さず、立体ハンドルと許可したAPIで操作させる。繰り返し形状と部分変更を短いコードで表せるため採用した。

## 造形API

- `extrude`、`revolve`、`loft`、`tube`、`mesh`、基本立体、変換、集合演算。
- `loft` は同じ頂点数の断面をつなぐ。XY上の凸形・星形、Z昇順を想定する。NURBS編集やスカルプトではない。
- `tube` はサンプル点を球の凸包でつなぐ近似。
- `stroke(controlPoints, radii, depthRatio)` は4制御点の3次ベジェ。24分割した楕円体間の凸包で先細り・膨らみ・扁平な曲線を近似する。1部品24本、半径0.4〜12mm、厚み倍率0.25〜1。
- `roundedBox(size,radius)` はXY輪郭の角丸で、Z方向は平ら。
- `union` は2〜16個の立体を順に結合する。その他のAPIも引数数を検査し、余分な値を黙って無視しない。

各関数の引数は `src/lib/design/model-script.ts` と `ai/freeform-skill.ts` を参照。曲面同士のフィレットや、写真との精密な一致は保証していない。

## 部分編集

`program.edit` は指定したトップレベル変数の初期値の式だけを置換する。ASTで式を検証し、代入・配列の変更・文の注入を拒否する。他のコード、色、配置、申告外寸を保持する。

共有変数を変更すると、複数の部位の形が変わることがある。対象の変数がどの部位に使われているか、変更後のプレビューで確認する。

## 実行制限と失敗時の扱い

AST深さ64、評価10万ステップ、配列割当3万要素、立体ハンドル384、各立体3万三角形・累計60万三角形に制限する。Workerは20秒で停止する。

サーバーが構造・構文・申告寸法、ブラウザが実メッシュを検査する。空・分離・実寸超過・コードエラーは適用しない。診断には行番号、実寸、分離した形の座標範囲などを含め、元の提案と一緒に修正処理へ戻す。成功まで元の設計を保持する。

修正が止まったら未完成であることを示し、再試行・相談を選べるようにする。最後の内部例外は画面に出さず、開発者向けconsoleに最大1000文字で記録する。コード全文・画像は記録しない。

## テストと未確認事項

自動テストでは固定サンプルのメッシュが閉じていること、正の体積と指定寸法を持つことを検査する。保存復元、部分編集、取り消し、出力も確認する。実AIによる生成例と、記録した応答の再生結果は [サンプル一覧](examples/README.md) を参照。

自動検査は最薄肉厚、すべての自己交差、サポート、接合・強度、実プリント、実機AR、着用適合を保証しない。形状検査に通っても、画像・依頼と見た目が一致するとは限らない。
