# AIチャット編集

`/create` の会話から設計の変更案を生成する。AI送信には一般会員ログインが必要。手動編集・保存・出力は [ブラウザ制作機能](house-editor.md) を参照。

## 操作と状態

スマホはチャットを先に、PCはプレビューと横並びに表示する。Enterで送信、Shift+Enterで改行し、日本語IME確定中は送信しない。発言は即座に表示し、AIの説明と実際の変更差分を区別する。

APIへ現在の設計、選択部品、直近8メッセージを送る。適用済み編集の履歴は実際の差分、相談の履歴は返答を使う。失敗・中止した発言は次回のAPI履歴に含めない。会話はタブ内メモリに保持し、再読込で消える。会話のクリアは設計を消さず、次の送信まで取り消せる。

## 編集の流れ

1. `POST /api/design/chat` で同一origin、JSON、セッション、入力上限、利用枠を確認する。
2. `src/lib/design/ai/harness.ts` がOpenAI Responses APIのStructured Outputsで編集案を得る。`ai-contract.ts` で変更先と値を限定する。
3. サーバーが構造・寸法・配置を検査し、失敗時だけ元の設計から1回修正する。各要求は最大45秒。形状修正要求ではモデル呼出は1回だけ。
4. ブラウザが再検証し、WASMで実メッシュを生成する。失敗した提案と診断を戻す修正処理を含め、1操作は最大3モデル呼出・140秒。サーバー内修正も合計へ算入する。
5. 検査成功かつrevision一致時だけ、履歴の1操作として適用する。手動変更・取消・読込・中止の後に古い案を適用しない。

同じ提案の再提出、同じ診断の繰り返し、予算切れで修正を止める。HTTP・認証・利用制限の失敗を無条件に再送しない。検証エラーと過去のモデル出力はデータとして扱い、developer指示へ昇格させない。

## モデル・接続・利用枠

既定モデルは通常編集・自由形状とも **`gpt-6-astra`**。正本は [harness.ts](../src/lib/design/ai/harness.ts)。採用はユーザー指定による。部分編集の実API確認はあるが、代表ケース全体での品質優位を証明した選定ではない。過去のmini系モデルの結果は現行モデルの成功率として扱わない。

`OPENAI_API_KEY` はサーバーだけで読み、ローカルはGit対象外の `.dev.vars` に設定する。値をブラウザ・モデル入力・ログへ出さない。D1には `0009_ai_design_usage.sql` が必要。配備時は [Cloudflare手順](../infra/cloudflare/README.md) に従う。

| 制限 | 値 |
| --- | --- |
| 指示・本文・履歴 | 指示1000文字、画像込み本文1MiB、履歴8件 |
| 参考画像 | 最大2枚。JPEG/PNGをブラウザで最大1024px・JPEG 300KiB以下へ再描画 |
| 利用枠 | UTC日付ごとに会員30要求・サービス全体300要求、同じ会員は8秒間隔 |
| 利用枠の保存 | ID・会員ID・時刻だけ。予約時に48時間より古い記録を削除 |

利用枠はD1の単一条件付きINSERTで予約する。失敗・中止も枠を消費し、ブラウザからの修正は別要求として数える。モデル呼出数・料金そのものの上限とは区別する。

画像は添付状態に保持し、削除するまで次回送信にも含める。画像データを設計JSON・会話テキストへ埋め込まない。指示・設計・会話・添付画像をOpenAIへ送る旨を画面に示す。`store:false` を指定するが、事業者側の全ログ保持を無効化する保証とはしない。

## 品質評価

通常の自動テストはモデル応答を模擬する。実モデルの日本語理解、見た目、依頼外変更の有無は別評価が必要。実メッシュ検査の成功も造形成功・見た目の一致を保証しない。

評価CLIは明示的な有料実行と呼出予算を必要とする。`scripts/evaluate-design-ai.ts` は旧モデル `gpt-4.1-mini` / `gpt-5-mini` だけを受け付けるため、以下は旧モデルの再現用。現行モデルの評価に使うにはCLIの更新が必要。複数回実行する場合は合算予算を別途決める。キーはこのCLIが読む `OPENAI_API_KEY` 環境変数またはGit対象外の `.env` に渡す（Worker用の `.dev.vars` とは別）。

```bash
node --experimental-strip-types scripts/evaluate-design-ai.ts --live --parts --max-calls=16
node --experimental-strip-types scripts/evaluate-design-ai.ts --live --freeform --max-calls=12
```

既存証跡は [サンプル一覧](examples/README.md)、基本編集の旧モデル比較は [評価JSON](evaluations/design-ai-model-comparison.json)。現在の検証範囲と追加すべき確認は [テスト評価](testing.md) を参照する。
